# TableManageShift

## API

| Prop            | Type     | Description                             | Default Value   |
|-----------------|----------|-----------------------------------------|-----------------|
| **dataSource** | `array`  | ข้อมูลตารางการทำงาน                      | `[]`           |
| **columns**    | `array`  | คอลัมน์ของตาราง                          | `[]`           |
| **onSelectChange** | `function` | ฟังก์ชันที่จะทำงานเมื่อมีการเลือกแถว   | -              |
